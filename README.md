# شبیه‌سازی تخصیص حافظه (First Fit و Best Fit)

این پروژه یک شبیه‌سازی ساده از الگوریتم‌های کلاسیک **تخصیص حافظه در سیستم‌عامل‌ها** است که با Python پیاده‌سازی شده است.

هدف این پروژه درک نحوه تخصیص درخواست‌ها (process/request) به بلوک‌های حافظه (memory blocks) با استفاده از دو استراتژی زیر است:

* First Fit
* Best Fit

---

## مفاهیم کلی

در سیستم‌عامل، حافظه به چند بلوک تقسیم می‌شود. هر بار یک درخواست حافظه وارد می‌شود و سیستم باید تصمیم بگیرد این درخواست در کدام بلوک قرار بگیرد.

این پروژه همین فرآیند تصمیم‌گیری را شبیه‌سازی می‌کند.

---

## الگوریتم‌ها

### 1. First Fit (اولین جای مناسب)

در این روش:

* از ابتدای لیست بلوک‌ها شروع می‌کنیم
* اولین بلوکی که اندازه کافی داشته باشد انتخاب می‌شود
* بلافاصله تخصیص انجام می‌شود

**مزایا:**

* سریع
* ساده

**معایب:**

* باعث هدررفت حافظه در طول زمان (fragmentation) می‌شود

---

### 2. Best Fit (بهترین تطابق)

در این روش:

* تمام بلوک‌ها بررسی می‌شوند
* کوچک‌ترین بلوکی که هنوز جواب بدهد انتخاب می‌شود

**مزایا:**

* استفاده بهینه‌تر از حافظه
* کاهش فضای هدررفته

**معایب:**

* کندتر از First Fit (چون کل لیست بررسی می‌شود)

---

## روند کار برنامه

1. کاربر وارد می‌کند:

   * تعداد درخواست‌ها
   * اندازه هر درخواست
   * تعداد بلوک‌های حافظه
   * اندازه هر بلوک

2. برنامه دو الگوریتم را اجرا می‌کند:

   * First Fit
   * Best Fit

3. بعد از هر تخصیص:

   * مقدار باقی‌مانده بلوک‌ها به‌روزرسانی می‌شود
   * اگر هیچ بلوکی مناسب نبود، درخواست رد می‌شود

---

## مثال

### ورودی:

```
درخواست‌ها: [212, 417, 112, 426]
بلوک‌ها:    [100, 500, 200, 300, 600]
```

---

### خروجی First Fit:

* 212 → 500
* 417 → 600
* 112 → 200
* 426 → تخصیص داده نمی‌شود

---

### خروجی Best Fit:

* 212 → 300
* 417 → 500
* 112 → 200
* 426 → 600

---

## ساختار کد

### 1. تابع دریافت عدد ایمن

این تابع ورودی کاربر را بررسی می‌کند و فقط عدد معتبر قبول می‌کند:

```python
def get_int(prompt, min_value=None, max_value=None):
    while True:
        raw = input(prompt)

        if not raw.lstrip('-').isdigit():
            print("عدد معتبر وارد کنید")
            continue

        value = int(raw)

        if min_value is not None and value < min_value:
            print(f"عدد باید >= {min_value} باشد")
            continue

        if max_value is not None and value > max_value:
            print(f"عدد باید <= {max_value} باشد")
            continue

        return value
```

### 2. پیاده‌سازی First Fit

```python
for i in darkhast:
    allocated = False

    for j in range(len(hofreh)):
        if hofreh[j] >= i:
            hofreh[j] -= i
            allocated = True
            break
```

---

### 3. پیاده‌سازی Best Fit

```python
for i in darkhast:
    best = -1

    for j in range(len(hofreh)):
        if hofreh[j] >= i:
            if best == -1 or hofreh[j] < hofreh[best]:
                best = j

    if best != -1:
        hofreh[best] -= i
```

## مفاهیم مهم

### Fragmentation (تکه‌تکه شدن حافظه)

وقتی حافظه به صورت نامنظم تقسیم شود، ممکن است فضاهای کوچک غیرقابل استفاده باقی بماند.

---

### Trade-off الگوریتم‌ها

* First Fit → سریع‌تر ولی کم‌دقت‌تر
* Best Fit → بهینه‌تر ولی کندتر
